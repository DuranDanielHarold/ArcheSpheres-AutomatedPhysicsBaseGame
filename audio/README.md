# Audio Assets

All shipped assets are original, procedurally synthesized PCM WAV files generated by
`tools/audio/generate_audio.py`; see `manifest.json` for the authoritative paths and
per-file metadata. No third-party samples are used.

## Layout and slots

```text
audio/
  manifest.json
  arena/bgm.wav
  <class-key>/weaponCollision.wav
  <class-key>/damage.wav
  <class-key>/ability.wav
  <ranged-key>/projectileThrow.wav
  <ranged-key>/projectileHit.wav
```

The class keys and available slots are defined by `audio/manifest.json`. The
`SPHERE_AUDIO` blocks in `js/classes/<class-key>.js` and `ARENA_AUDIO.bgm` in
`js/data/audioConfig.js` are generated from that manifest.

## Add or replace audio

- To replace a sound, overwrite the corresponding WAV while keeping its manifest path.
- To add or remove a class slot, update the manifest and regenerate the affected assets.
- Run `python tools/audio/apply_sphere_audio.py` to synchronize class/config path blocks.
- Run `python tools/audio/check_paths.py` to verify every manifest path exists and the
  class/config registrations match.
- Keep files as mono 16-bit PCM WAV at 44.1 kHz.

## Regeneration and verification

Install the generator requirements with `pip install numpy scipy`, then run:

```powershell
python tools/audio/generate_audio.py --root .
python tools/audio/generate_audio.py --root . --only knight,arena
python tools/audio/generate_audio.py --root . --verify
python tools/audio/apply_sphere_audio.py --check
python tools/audio/check_paths.py
```

Generation is deterministic. Tune class recipes in `tools/audio/recipes.py` or the
`CLASSES` table and slot loudness targets in `tools/audio/generate_audio.py`, then
regenerate only the affected class. The mastering chain DC-blocks, trims, fades,
normalizes to the slot target, soft-limits to a -1 dBFS peak ceiling, and dithers to
16-bit PCM.
