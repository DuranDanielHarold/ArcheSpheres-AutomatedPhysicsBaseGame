# Privacy Statement

ArcheSpheres is a client-side browser game repository.

## What the project does not do

- It does not require user accounts.
- It does not collect analytics by default.
- It does not send gameplay data to a backend service.
- It does not store personal information in the repository itself.

## What contributors should avoid committing

- personal API keys
- `.env` files
- local machine paths
- private recordings or captures
- unrelated personal documents

## Audio and media notes

All audio assets committed to this repository should be files you have permission to use, modify, and distribute.

## Local use

When run locally as static HTML, the game executes in the browser on the local machine. Any browser-level privacy behavior, caching, or media playback policy is determined by the browser being used.
